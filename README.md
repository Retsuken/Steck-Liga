# СтекЛига

Платформа подбора ИТ-специалистов: работодатель находит **категорию** (специализация + грейд по тесту) и сам выходит на кандидата с приглашением и вилкой зарплаты. Достижения ФСП усиливают позицию в категории; отсутствие истории ФСП — штатный сценарий.

Сопроводительная документация: [`docs/СОПРОВОДИТЕЛЬНАЯ_ДОКУМЕНТАЦИЯ.md`](docs/СОПРОВОДИТЕЛЬНАЯ_ДОКУМЕНТАЦИЯ.md).  
Презентация механик в продукте: страница `/pitch/`.

## Локальный запуск

Нужны Python 3.12+ и pip.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
mkdir data
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Откройте http://127.0.0.1:8000/

## Docker

```bash
docker compose up --build
```

Сервис на порту 8000, SQLite в `./data`.

## Сквозной сценарий для жюри

1. Войти как `anna@demo.ru` — кабинет, категория, входящее приглашение, принять.
2. Выйти, войти как `hr@severcode.ru` — контакты Анны открылись.
3. Потребность «Backend Middle» → подборка с обоснованием (Анна/Мария в топе).
4. Банк кандидатов, фильтр «без/с ФСП».
5. Зарегистрировать нового кандидата, пройти опрос и тест, увидеть присвоение категории.
6. Классический отклик: кандидат `pavel@demo.ru` уже откликнулся на Frontend Middle.
